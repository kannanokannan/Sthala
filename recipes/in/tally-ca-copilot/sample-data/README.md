# Sample Data — Tally CA Copilot

Place anonymised sample Tally exports, GST JSONs, and PDF invoices here for testing.

Required for CI:
- `tally/sample-vouchers.xml` — anonymised Tally XML with ~50 vouchers
- `gst/sample-gstr3b.json` — anonymised GSTR-3B JSON
- `invoices/sample-invoice.pdf` — anonymised scanned invoice

All data must be fully fictional. No real GSTINs, amounts, or party names.
