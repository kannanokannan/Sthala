## Data Source Reality (the actual moat)

### Tally Integration (Critical)
- Proprietary `.900` / `.1800` file formats
- ODBC available but memory crash at >500 voucher batches
- TDL (Tally Definition Language) preferred for complex reports
- **Whoever builds reliable Tally→AI pipeline first owns CA firm market**

### Other Sources
- Zoho Books: 100 req/min limit, 20 refresh token cap, regional domain routing
- BUSY Accounting: SQL-accessible, alternative to Tally for many SMBs
- Vyapar: Excel export, simpler than Tally
- WhatsApp Business: order data in .txt chat exports

## Indic AI Landscape

- **Sarvam-30B (Apache 2.0):** MoE, 2.4B active/32B total, fits 24GB VRAM Q6_K
- **OCR breakthrough:** Bhashini PARSeq = 73%+ WRR vs Tesseract 15% on Indic scripts
- **Tokenizer fertility:** Sarvam ~2.27 vs Gemma 3.07 — 2-4× compute saving on Tamil/Hindi text

## Three Defensible Wedges

1. **MCA/DPDP Compliant Tally Copilot for CA firms** (highest readiness, fastest sales cycle)
2. **Indic-First Document Node for logistics/pharma distributors** (large TAM, refurb-friendly)
3. **Air-Gapped Sovereign AI Server for manufacturing** (premium, compliance-driven)

## Sales Cycle Reality

- CA firms / distributors: 2–8 week decision cycle
- Schools: 6–18 month decision cycle (recommend last)
- Manufacturing: 3–12 months

**Strategy: Start with CA firms and distributors for revenue. Use credibility to enter schools.**
